# 갈피 · Y Labs

**만화와 소설, 읽던 곳부터.** Windows용 만화·소설 뷰어 갈피의 공식 배포 저장소입니다.

## 다운로드

- [갈피 다운로드 및 다운로드 횟수 확인](https://silnoone.github.io/galpi/)
- [0.2.1 Windows ZIP 바로 다운로드](https://github.com/SilnoonE/galpi/releases/download/v0.2.1/Galpi-0.2.1-Windows.zip)
- [모든 버전과 릴리스 안내](https://github.com/SilnoonE/galpi/releases)

ZIP을 압축 해제한 뒤 **Galpi.exe**를 실행하세요. 테스트용 만화·소설 샘플과 사용 안내가 함께 들어 있습니다.

Windows 10/11 · .NET Framework 4.8 · 설치/로그인 없이 실행.

## 주요 기능

- TXT 소설, ZIP/CBZ 만화, 이미지 파일·폴더 읽기
- 책장 검색, 즐겨찾기, 정렬, 읽기 진행 표시
- 읽던 위치 저장 및 복원
- 책장 제목 수정, 실제 파일·폴더 이름 변경, 원본 다시 연결
- 저장한 갈피와 F11 전체화면 읽기
- 글꼴, 글자 크기, 줄 간격, 밝은/어두운 테마
- 책장 전용 Y Labs 자사 홍보 배너

## 다운로드 횟수

다운로드 페이지는 GitHub 공개 API의 릴리스 파일별 `download_count`를 조회합니다. Windows ZIP만 합산합니다. 중복 다운로드를 포함하므로 사용자 수나 실제 실행 횟수와 다릅니다. 페이지의 **통계 새로고침**으로 현재 수치를 확인할 수 있습니다.

[v0.2.1 공개 API](https://api.github.com/repos/SilnoonE/galpi/releases/tags/v0.2.1)

## 베타 안내

현재 버전은 코드 서명 전 베타입니다. PDF/EPUB/RAR/CBR 및 자동 업데이트는 지원하지 않습니다. 소설의 읽기 위치는 스크롤 비율 기준으로, 창 크기나 글꼴에 따라 정확한 문장 위치는 달라질 수 있습니다.

책 내용·파일명·읽기 기록은 서버로 보내지 않으며 실행 통계도 수집하지 않습니다. 기본 배너는 자사 홍보이며 광고 클릭만으로 수익이 발생하지 않습니다.

## 개발 소스

이 저장소는 실행 파일 배포와 안내 자료용입니다. 갈피 프로그램의 개발 소스는 공개하지 않습니다. GitHub가 자동으로 표시하는 **Source code ZIP/TAR**는 이 안내 자료의 압축 파일이므로, 실행하려면 **Windows.zip**을 받으세요.
